# tmux Configuration

This directory is a placeholder for tmux configuration.

No tmux.conf was found on this system - only the TPM (Tmux Plugin Manager) was detected at `~/.tmux/plugins/tpm`.

## Setup TPM

If you need tmux plugins, install TPM:

```bash
git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm
```

Then create your `~/.tmux.conf` and add plugins as needed.
